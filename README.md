## 🏛️ The 4-Pillar Evidence Architecture

Never submit an emotional or one-sentence appeal (e.g. *"Please unban me, I didn't break any rules"*). TikTok's Tier-2 Risk Specialists require a structured, 4-pillar evidence packet submitted as a single multi-page PDF (`[BrandName]_TikTok_Verification_Documents.pdf`):

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       THE 4-PILLAR EVIDENCE PACKET                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 🏛️ PILLAR 1: CORPORATE ENTITY (State registry, Good Standing, Tax EIN)      │
│ 💳 PILLAR 2: FINANCIAL SOLVENCY (Bank statement, matching ending digits)    │
│ 🛡️ PILLAR 3: CREATIVE COMPLIANCE (Ad script remediation, policy parity)     │
│ 📦 PILLAR 4: SUPPLY CHAIN LEGITIMACY (Tracking numbers, delivery proof >95%)│
└─────────────────────────────────────────────────────────────────────────────┘
```

### 🚨 Redaction Standards
* **The 4-Digit Rule**: Always black out the first 12 digits of payment cards. Display only the **Last 4 Digits** and the **Cardholder Name**.
* **Financial Privacy**: Redact sensitive non-TikTok transactions, but preserve the bank institution header, company address, and TikTok test authorization charges.
